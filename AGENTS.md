# Agenten

Die Anleitung für Coding-Agenten (Claude Code, Codex, Copilot, Cursor, …) steht in [CLAUDE.md](CLAUDE.md). Kurz:
eigener Branch und Pull Request, nie direkt auf `main`; `npm test` und `npm run build` müssen durchlaufen; Pfade und
Front Matter nicht umbauen, weil Ditarr sie verwendet; keine Inhalte erfinden.
