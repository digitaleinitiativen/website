Seit dem Lockdown halten wir unsere monatlichen Meetups remote ab. So auch letzte Woche Dienstag, mit einem Remote-Teilnahmerekord von 20 Personen. Grund dafür war auch sicher das spannende Thema, welches von Christoph Klocker vorgetragen wurde.

Es ging darum Web-Applikationen ohne JavaScript zu schreiben. Ein durchaus gewagtes Unterfangen, da im Browser ja eigentlich mehr oder weniger nur JavaScript mit vollem Funktionsumfang läuft. Christoph hat allerdings gleich wieder etwas zurück gerudert, und erläutert, dass JavaScript durchaus noch notwendig ist, nur wird das schon von [Phoenix LiveView](https://github.com/phoenixframework/phoenix_live_view), einem Framework für die Programmiersprache [Elixir](https://elixir-lang.org/), bereitgestellt. Entwickler haben anschließend die Möglichkeit auch das client-seitige User Interface am Backend zu implementieren.

Auch die anschließende Diskussion war sehr aufschlussreich. Ich denke es konnten sich alle darauf einigen, dass dieses Vorgehen vor allem für datengetriebene Applikationen sehr erfolgsversprechend ist, da die client-seitigen Transformationen trotzdem eine Internetverbindung benötigen.

Alles in allem ein sehr gelungenes Meetup. Wir freuen uns schon auf die nächste [Veranstaltung am 9. Februar](https://www.meetup.com/de-DE/VlbgWebDev/events/llpqfryccdbmb/).
