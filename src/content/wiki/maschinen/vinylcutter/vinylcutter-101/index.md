**Textilien:** Bestenfalls ohne Plastikanteil und mit glatter Oberfläche -> muss Hitze aushalten und die Folie muss gut darauf haften können

## How to get started

1.  Öffne _Inkscape_
    
2.  _svg_ Datei öffnen: File > Open…
    

**Größe kontrollieren:** kontrollieren, ob Grafik/Text ein Pfad ist (sonst: path > object to path; dann Gruppierung aufheben object > ungroup >> path > union)  
Warum? Weil es sonst sein kann, dass Buchstaben/Objekte zerschnitten werden.

**Bei Textilfolie:** Spiegeln! (>Flip selected objects horizontally (H))

**Bei Stickerfolie:** braucht man Transferfolie; nach dem Schnitt werden die überschüssigen Folienteile gelöst; das Objekt wird dann auf Transferfolie geklebt

### Folie einlegen

-   Bei Fl_exfolie (_Textilfolie): Matte Seite klebt am Ende auf der Textilie > matt liegt beim Schneideplotter oben
    
-   _Bei Stickerfolie_: Weiße Fläche liegt beim Einspannen in den Plotter unten und darf nicht geschnitten werden
    

→ Rad muss innerhalb der weißen Markierung sein; Räder müssen noch auf der Folie sein  
Dann wird Rolle mittels Spanner gespannt.

**Bedienungsfeld am Schneideplotter:**  
Roll: misst nur Breite  
Piece: misst Länge und Breite  
Edge: misst Teilbreite (wenn ich nur ein Stück von der Rolle verwende)

'Origin‘ wird gesettet > mittels Pfeiltasten an den Rollenanfang fahren (ganz vorne links) und lange ‘Origin’ drücken bis es sich auf dem Bildschirm verändert)

⚡ **Druckstärke des Schneidmessers**  
_→_ kann man direkt beim Vinylcutter verstellen. Die Einstellung ist im Normalfall richtig eingestellt

-   120 Druck für normale Flexfolien
    
-   150 Druck für Beschriftungsfolien
    
-   240 Druck für Glitzerglitzerfolien
    

_Noch unsicher?_ Nütze die Testfunktion!  
_→_ Cutter schneidet nun ein kleines Symbol und man sieht, ob die Folie korrekt geschnitten wird

![](/wiki-files/20217857/img-7244.heic)

→ so wird die Rolle eingelegt

### Inkscape

→ Programm öffnen

→ Foliengröße einstellen: _File > Document Properties_  
Dabei können die ‘_Default units’_ auf mm, die ‘_Units’_ auf mm und die Papierbreite auf die im Plotterdisplay angezeigte Folienbreite eingestellt werden. Dies ändert nichts an deiner Datei. Es kann dir nur dabei helfen, die maximale Breite der Folie auszunutzen.

→ Import von Grafiken (bestenfalls im Vektorformat; sonst muss zuerst vektorisiert werden)

→ Maschinennullpunkt ist die untere linke Ecke.

✍ **Text hinzufügen**

→ Textfeld aufziehen und gewünschten Text hineinschreiben

→ Text vektorisieren:

…………. Text auswählen → _Path > Object to Path_ ( Shortcut Strg+Shift+C)

…………. Text ent-gruppieren → _Object > Ungroup_ (Shortcut Strg+Shift+G)

…………. Objekt vereinigen → _Path > Union_ (Shortcut Strg + '++')

**Du bist dir nicht sicher, ob die Größe deiner Grafik passt?**

Schicke deine Datei aus dem Inkscape einfach an unseren Bürodrucker (Color Laserjet MFP M477fdn). Achtung → 100% Skalierung ⚡️  
Einfach ausschneiden, auf dein T-Shirt oder ähnliches kleben und anprobieren 👻

### File via Inkcut (neues Programm am Desktop) zum Vinylcutter schicken:

_→ Datei > Öffnen (Kontrolle: Spiegeln? Größe?)_

_→ live > start > start_

**Fertig?**  
_→_ Spanner raus, Folie wegräumen und Computer runterfahren

### Heizplatte

-   Einschalten (links neben der Anzeige)
    
-   Warten bis die voreingestellte Hitze erreicht wurde (ca. 170°C, [mehr Infos](/wiki/maschinen/vinylcutter/vinylcutter-faqs/temperatur-einstellen/))
    
-   T-Shirt so auf die Ablage der Thermopresse legen, dass der Stoff flach liegt und keine Falten im Stoff sind. Druck auf den Stoff legen. Achtung! Die klebige Seite muss auf dem Stoff liegen, die nicht-klebende Plastikseite liegt oben.
    
-   Presse auf den Stoff drücken, Timer drückern und Countdown abwarten, auskühlen lassen. Lässt sich die Trägerfolie lösen? Wenn nicht, dann Vorgang wiederholen.
    
-   Gerät ausschalten
    

### Materialverbrauch eintragen

Folien werden nach [Verbrauch](https://xiberg.eu/di/calc2/#) verrechnet. Hier wird nur die Länge des verbrauchten Materials (ab 5 cm) angegeben. Restmaterialien können mitgenommen oder für die Allgemeinheit als gratis Material hinterlegt werden.
